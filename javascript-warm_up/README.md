# JavaScript - Warm up

First scripts in JavaScript, run with Node: variables, arguments, conditions,
loops, functions, objects and modules.

## Files

| File | Description |
| --- | --- |
| `0-javascript_is_amazing.js` | Prints a constant |
| `1-multi_languages.js` | Prints 3 lines |
| `2-arguments.js` | Says whether 0, 1 or more arguments were passed |
| `3-value_argument.js` | Prints the first argument, without using `length` |
| `4-concat.js` | Prints `<arg1> is <arg2>` |
| `5-to_integer.js` | Prints the first argument as an integer, or `Not a number` |
| `6-multi_languages_loop.js` | Same 3 lines as task 1, from an array and a loop |
| `7-multi_c.js` | Prints `C is fun` x times |
| `8-square.js` | Prints a square of `X` |
| `9-add.js` | Adds two integers with `add(a, b)` |
| `10-factorial.js` | Recursive factorial, `NaN` gives 1 |
| `11-second_biggest.js` | Second biggest integer in the arguments |
| `12-object.js` | Changes a value inside an object |
| `13-add.js` | Exports an `add` function |

## Requirements

- Ubuntu 20.04 LTS, Node 14
- First line of every file: `#!/usr/bin/node`
- Code style checked with `semistandard` (16.x)
- No `var`
