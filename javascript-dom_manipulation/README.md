# JavaScript - DOM manipulation

Scripts that run in the browser: select elements, change their style, classes
and text, react to clicks and load data with the Fetch API, all without
reloading the page.

Open any `N-main.html` in Chrome to try the matching `N-script.js`.

## Files

| File | Description |
| --- | --- |
| `0-script.js` | Colors the header red with `document.querySelector` |
| `1-script.js` | Colors the header red when `#red_header` is clicked |
| `2-script.js` | Adds the `red` class to the header on click |
| `3-script.js` | Switches the header between `red` and `green` on each click |
| `4-script.js` | Adds `<li>Item</li>` to `ul.my_list` on each click |
| `5-script.js` | Changes the header text to `New Header!!!` on click |
| `6-script.js` | Fetches a Star Wars character and shows its name in `#character` |
| `7-script.js` | Fetches every Star Wars movie and lists the titles in `#list_movies` |
| `8-script.js` | Fetches "hello" in French into `#hello`, works when loaded from `<head>` |

## Requirements

- Chrome 57 or later
- Code style checked with `semistandard`
- No `var`
